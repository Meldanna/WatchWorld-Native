# T16 - 侧边栏功能入口接线

## 目标

把侧边栏底部 8 个功能图标从 `/* TODO */` 接上实际功能。
每个功能打开**独立弹窗**，共用统一壳子 `FeatureDialog`。

## 弹窗壳子设计

```
┌──────────────────────────────┐
│ ✕   弹窗标题                 │  ← 顶部：左「✕」关闭 + 标题
│──────────────────────────────│
│                              │
│  （各 Panel 内容）            │  ← 可滚动
│                              │
└──────────────────────────────┘
```

## 步骤

### 1. 新建 `ui/settings/FeatureDialog.kt`

```kotlin
@Composable
fun FeatureDialog(title: String, onDismiss: () -> Unit, content: @Composable () -> Unit) {
    Dialog(onDismissRequest = onDismiss, properties = DialogProperties(usePlatformDefaultWidth = false)) {
        Surface(Modifier.fillMaxSize().padding(16.dp), shape = extraLarge, tonalElevation = 2.dp) {
            Column(Modifier.fillMaxSize()) {
                Row(Modifier.fillMaxWidth().padding(horizontal = 8.dp, vertical = 4.dp), verticalAlignment = CenterVertically) {
                    IconButton(onClick = onDismiss) { Icon(TablerIcons.X, "关闭") }
                    Spacer(Modifier.width(8.dp))
                    Text(title, style = titleMedium)
                }
                HorizontalDivider()
                Column(Modifier.weight(1f).fillMaxWidth().verticalScroll(rememberScrollState()).padding(16.dp)) {
                    content()
                }
            }
        }
    }
}
```

⚠️ 先确认 X 图标名：`jar tf xxx.jar | Select-String 'XKt'`

### 2. SidebarSheet.kt — 拆回调

签名扩展为 8 个回调（`onOpenMcp`/`onOpenSkill`/...），`SidebarNavGrid` 同步改。

### 3. App.kt — 弹窗状态 + FeatureDialog

新增 7 个 `var xxxOpen by remember { mutableStateOf(false) }`。

SidebarSheet 接线：保留侧边栏作为父层并打开目标弹窗 → load 数据。弹窗关闭后回到侧边栏，保留搜索条件、列表位置和折叠状态；侧边栏本身也通过 Dialog 接收平台返回操作。

弹窗区域用 `FeatureDialog(标题, 关闭) { XxxPanel(...) }`。

## 验收

1. 编译零错误
2. 每个图标：侧边栏保留在弹窗下方 → 弹窗（✕ + 标题 + Panel）；关闭按钮、遮罩和系统返回关闭弹窗后均回到侧边栏

- 各 Panel 在 `SettingsPanels.kt`，public 可直接引用
